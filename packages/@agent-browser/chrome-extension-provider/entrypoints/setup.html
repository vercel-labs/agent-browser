Agent Browser

Choose a page to control

Connect a CLI session, select an open page, and authorize it. You can stop control here at any time.

Connect a session

Run chrome-extension.setup in the CLI, then paste its pairing code below.

If Chrome asks, allow this extension to connect to a service on this device.

Sessions

Authorization follows the selected tab as it navigates. Its pages use your existing Chrome profile and signed-in accounts. Other tabs are not added to the session.

Closing or restarting the connection ends authorization. Run setup again to start a new session.
