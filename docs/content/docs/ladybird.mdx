Drive the [Ladybird](https://ladybird.org/) browser, an independent engine built from scratch, through its WebDriver server. agent-browser spawns Ladybird's `WebDriver` binary, opens a session, and shuts both down on `close`.

## Requirements

Install Ladybird from [ladybird.org/download](https://ladybird.org/download/). agent-browser looks for the WebDriver binary in these places, in order:

## Basic usage

Use `-p ladybird` (or `AGENT_BROWSER_PROVIDER=ladybird`). Ladybird runs headless by default; add `--headed` to show the window.

```bash
agent-browser -p ladybird open https://example.com
agent-browser -p ladybird snapshot -i
agent-browser -p ladybird fill @e2 "user@example.com"
agent-browser -p ladybird click @e3
agent-browser -p ladybird eval "document.title"
agent-browser -p ladybird screenshot page.png
agent-browser -p ladybird close
```

## Supported commands

Ladybird uses the WebDriver backend, the same one Safari and iOS use. These commands work: `open`, `snapshot` (including `-i`, `-c`, `-d`, `-s`, and `--urls`), `click`, `hover`, and `fill` with `@eN` refs or CSS selectors, `get url`, `get title`, `eval`, `screenshot`, `back`, `forward`, `reload`, `cookies`, and `close`.

`snapshot` walks each frame's DOM, including open shadow roots and iframes, and computes roles and names in the page, so its output follows the Chrome format. Each `@eN` ref is the browser's own element reference, kept with its iframe path, and stays the same across snapshots of the same page. `click` and `hover` scroll the element into view and use a pointer action, which also reaches elements inside open shadow roots. When the page has changed since the snapshot, a ref reports that it is stale; run `snapshot` again.

## Limitations

- Commands that need the Chrome DevTools Protocol are not available, including `a11y`, network routing and HAR, tracing, profiling, screencast, and init scripts. `get text`, `find`, and `tab` commands are not available yet.
- Roles and names are computed by agent-browser rather than read from the browser's accessibility tree, so a few elements can differ from Chrome. Closed shadow roots are not included.
- `click` supports a plain left click only.
- `--allowed-domains` is rejected because WebRTC containment cannot be enforced.
- A headless Ladybird session follows the default idle timeout. A headed session is exempt, like other headed browsers.
