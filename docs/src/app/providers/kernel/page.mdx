# Kernel

[Kernel](https://www.kernel.sh) provides cloud browser infrastructure for AI agents with features like stealth mode and persistent profiles.

## Setup

```bash
export KERNEL_API_KEY="your-api-key"
agent-browser -p kernel open https://example.com
```

Or use environment variables for CI/scripts:

```bash
export AGENT_BROWSER_PROVIDER=kernel
export KERNEL_API_KEY="your-api-key"
agent-browser open https://example.com
```

The `-p` flag takes precedence over `AGENT_BROWSER_PROVIDER`.

**Profiles:** profiles must be created in Kernel before use. The provider loads an existing profile and does not create one. Cookies and logins are only written back when `KERNEL_PROFILE_SAVE_CHANGES` is set, so a read-only run can reuse a profile without modifying it. Set either the name or the ID. If both are set, the ID is used.

**Proxies:** set at most one of `KERNEL_PROXY_ID`, `KERNEL_PROXY_NAME`, or `KERNEL_PROXY_MODE`. Proxy selection changes egress only. It does not turn stealth or the CAPTCHA solver on or off. With none of them set, a stealth session uses Kernel's default stealth proxy and a non-stealth session uses direct egress.

`KERNEL_REGION` requires a Start-Up or Enterprise plan, and the region is fixed once the session starts.

When enabled, agent-browser connects to a Kernel cloud session instead of launching a local browser. All commands work identically.

Get your API key from the [Kernel Dashboard](https://dashboard.onkernel.com).
